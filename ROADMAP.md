# Roadmap / 路线图

## 1.1.x - Java intelligence / Java 智能索引增强

- tree-sitter-java or JavaParser adapter.
- Method-level endpoint and Feign mapping extraction.
- Spring Bean dependency graph.
- Maven/Gradle module graph.

## 1.2.x - Memory quality / 记忆质量增强

- File summary refresh.
- Task memory deduplication.
- Incident memory import.
- Rule recommendation workflow.
- Verified-case scoring.

## 1.3.x - Enterprise Spring Cloud integrations / 企业级 Spring Cloud 集成

- Nacos config fetcher.
- RocketMQ/Kafka config enrichment.
- Elasticsearch index alias usage indexing.
- MongoDB collection usage indexing.
- Redis key and cache usage indexing.

## 1.4.x - Semantic retrieval / 语义检索

- Optional embedding index.
- Hybrid keyword + vector retrieval.
- Explainable reranking.
- Local model adapter.

## 2.0.0 - Stable shared memory platform / 稳定公共记忆平台

- Stable MCP tool schemas.
- Stable workspace/rule/memory specs.
- Migration support for memory formats.
- Web UI topology viewer.
- Rule package ecosystem.
