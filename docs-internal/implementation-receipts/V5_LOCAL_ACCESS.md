# 5.0.0b2 本机免认证改造回执

日期：2026-10-10。

默认 `local` 模式下，管理页面自动加载项目列表，MCP 无需令牌即可访问全部已登记项目和工具。新增项目在现有 MCP 连接中动态可见；项目暂停状态、明确项目路由以及 session 与项目的一致性校验仍生效。所有本机客户端共用管理身份，不提供客户端私有数据隔离。

原凭据模式通过 `--auth-mode token` 或 `MEMORY_CENTER_AUTH_MODE=token` 显式开启，保留项目授权、读写权限、凭据撤销和限流。MCP 工具 schema 不变；默认访问策略发生变化，状态响应新增 `auth_mode` 字段。

原生服务默认监听回环地址，免认证模式拒绝普通非回环监听。容器使用 `--container-local`，Compose 仅将端口发布到宿主 `127.0.0.1`；该选项本身不隔离容器内部网络。管理 API 与 MCP 保留 Host、Origin 和 JSON 请求类型检查，禁用代理头信任。
