用户已授权连续实现，不再等待 S2/S3/S4 切片确认。S0/S1 回执保留历史状态；本回执与 [平台指南](../V5_PLATFORM_GUIDE.md) 描述当前实际行为。没有推送或发布正式版本。

## 已实现范围

- 常驻 FastAPI/Uvicorn 服务、官方 MCP Streamable HTTP、共享生命周期、就绪检查、数据目录独占锁、正常关闭与重启。
- 稳定项目/服务身份、识别预览、登记、分页、改名、暂停/恢复与移除接入；不读取或导入旧 workspace/registry。
- 按项目、主体和工具授权的凭据、撤销、限流、MCP 目录过滤与调用复核；会话/引用/任务不能跨主体复用。stdio 是新版 HTTP 服务的传输代理。
- 两个有界索引子进程、持久任务队列、进度、取消、重试、中断恢复、资源预算；成功后原子发布 generation，失败保留上一代。派生配置与索引只写服务目录。
- SQLite 轻量模式和 PostgreSQL + pgvector 标准模式。PG 保存平台业务记录与向量；工程事实引擎仍在每个 generation 使用既有 SQLite 事实库。
- 中文 bigram/英文标识符 BM25、Ollama/OpenAI-compatible 嵌入、模型档案隔离、PG HNSW/距离检索与 RRF 融合。未配置模型时提供关键词检索。
- 文本、Markdown、PDF、DOCX 文档导入；Wiki 来源摘录草稿、人工编辑、修订冲突和回滚；长期记忆确认/拒绝/替代/过期。修订或删除来源立即失去召回与引用资格。
- Vue 管理页面：项目、任务、知识库、Wiki、长期记忆、模型设置和 MCP 接入。数据来自真实 API，无演示数据注入。
- wheel/sdist、随包前端资源、独立安装脚本、Compose/PG 部署、停机文件/SQLite 快照备份及全新目录恢复。

## 尚未完成的发行验收与能力边界

- 真实 Ollama 模型下载遇到当前网络的证书校验错误，未绕过 TLS。协议/数值夹具不是实际语义质量评测；正式版本仍需已部署模型与真实检索样本验收。
- 未执行大型私有工程性能回放、amd64 镜像矩阵及长期压力测试，因此保留 b1。PG 镜像正式发布前需固定验收摘要。
- 默认包/容器不含多语言 AST 扩展；Java 基础解析与多语言关键词检索可用，其它 AST 事实解析需选装 `multilang`。
- Wiki 草稿是有引用的来源摘录，需要人工整理；没有实现自主 Agent 推理、自动图谱维护或生成式聊天。
- 图片里的 IM、浏览器/会话沙箱、联网搜索、Redis 分布式队列、Neo4j、外部向量库和所有模型厂商不在本轮服务化核心交付范围。
- 源文档存数据库，未增加独立对象存储；当前为单服务实例的本机部署，不声称多副本高可用。所有输入/召回受指南中的预算限制。
