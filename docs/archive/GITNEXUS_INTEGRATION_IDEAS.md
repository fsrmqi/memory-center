# GitNexus-inspired Ideas / GitNexus 思想融合

This project does not copy GitNexus. It absorbs several advanced ideas and specializes them for Spring Cloud workspaces.

本项目不复制 GitNexus，而是吸收其先进思想，并面向 Spring Cloud 多项目场景做特化。

## Integrated ideas / 已融合思想

1. Precomputed relational intelligence / 预计算关系智能
2. Knowledge graph over flat file search / 从文件搜索升级为知识图谱
3. Impact analysis / 影响面分析
4. 360-degree context view / 符号上下文视图
5. Detect changes / Git diff 风险映射
6. Agent skills / Agent 技能文件生成
7. Wiki generation / Wiki 自动生成
8. Local-first architecture / 本地优先，不上传代码
9. Registry and group concept / 全局 Registry 与逻辑分组
10. MCP-native access / MCP 原生访问

## Spring Cloud specialization / Spring Cloud 特化

Memory Center focuses on:

- Feign → Controller matching
- MQ topic → consumer mapping
- shared DTO and message compatibility
- application.yml/bootstrap.yml configuration index
- oldPubTime/newPubTime data migration rules
- Elasticsearch/MongoDB/DB safety rules
- enterprise logging and observability rules

## Non-goals / 非目标

- Not a universal 14-language parser in the first release / 第一阶段不追求 14 种语言
- Not a full graph UI in the first release / 第一阶段不做完整 Web 图谱 UI
- Not a cloud service / 不是云服务，不上传代码
