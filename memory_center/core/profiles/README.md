# 工作区画像

提供用户自定义的项目约定：命名别名、默认知识范围、Wiki 拓扑与配置命名空间。

`loader.py` 负责从 `workspace.yaml`、profile 文件或 `MEMORY_CENTER_PROFILE` 环境变量加载并校验画像；`model.py` 定义 `Profile` 等不可变数据结构。

设计约定：

- profile 是**数据**，不是代码插件——内部使用方只需提供一份 YAML，公开仓库与内部使用之间不存在代码分歧。
- 画像为空时所有消费方必须降级运行（中性默认），不得抛错。
- 字段新增保持向后兼容；未知字段报错，以便尽早发现拼写错误。

边界：本模块只做加载与校验，不承载工作区 I/O 编排；需要画像的领域模块从 `core.profiles` 引入，不直接读 profile 文件。
