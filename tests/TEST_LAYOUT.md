# Test Layout / 测试布局

- `entrypoints/`：CLI、MCP、HTTP、Hook 与公开文档契约。/ Public entry contracts.
- `index_storage/`：索引、解析、SQLite、性能、新鲜度和工作区生命周期。/ Indexing and storage.
- `domain/`：检索、推理、契约、断言、本体、任务与业务流。/ Domain analysis.
- `regression/`：跨模块回归、历史场景和版本化协议快照。/ Historical regression.

`fixtures.py`、`conftest.py` 和项目资源映射属于共享测试基础设施。
